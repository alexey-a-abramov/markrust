# Skills

| Skill | What it does |
| --- | --- |
| `swarm` | Project state: staged, unstaged, untracked and unpushed changes, **snapshot diff**, plus a confirmation step for backup. Registry: `~/Projects/AGENTS.md`. |
| `sessions` | Which **model and permission mode** each session uses; interrupted sessions classified as stalled or recovered with `claude --resume` commands. |
| `stash` | Triage stashes across projects: age, message, diff summary, and recovery commands. |
| `usage` | **Token usage and cost** per project and session; cache reads shown separately. |
| `worktrees` | Find worktrees including stale branches and missing directories, with removal previews. |
| `digest` | What changed since a date: new commits per repository and a concise standup summary. |

End of table fixture.
