# MarkRust WYSIWYG engineering notes — status & handoff

_Last updated: 2026-09-14. This is the detailed design and verification handoff for the "real WYSIWYG editor" effort. The concise, canonical product plan is [the root roadmap](../ROADMAP.md)._

## Vision (locked decisions)

MarkRust becomes a **true WYSIWYG markdown editor**: the user edits a rendered rich document (Typora-style: delimiters hidden unless the caret or a selection intersects the node); Markdown is the on-disk serialization format. Additionally: a **pure source** mode (the existing Typora-style delimiter-masking editor) and a **side-by-side** mode. All native Rust on **GPUI**, fast.

- v1 scope: core rich text + tables (cell editing, row/col ops) + inline images + frontmatter panel. Mermaid WYSIWYG is future (renders as inert code block; extension point kept).
- Save flow: **block-preserving by default** (untouched blocks keep exact original bytes). A diff dialog (Keep original / Normalize / Cancel) appears only when formatting beyond the user's edits would change — with the source-primary architecture that means only on an explicit Normalize action.
- Reuse: MIT/BSD sources fine with attribution (see `THIRD-PARTY-NOTICES.md`); no GPL. References cloned at `~/Projects/github_sources/{tui.editor,nimbalyst}`.

## Architecture: source-primary, tree-projected (the key decision)

**The rope buffer stays the single source of truth.** A derived `RichTree` (in `markrust-core::rich`) is authoritative for interpretation and command targeting. Every rich command compiles down to byte splices on the source, produced by re-serializing only the touched top-level block(s). Consequences:

- Block-preserving save is free: untouched blocks are untouched bytes. Default save writes the buffer verbatim.
- Undo stays byte-based (`UndoStack`/`EditOperation` keep working for both modes).
- Caret/selection stay source byte offsets; `RichEngine` provides delimiter-skipping snap/step and source↔visible mapping. Quote markers (`>`), list markers (`- ` / `1. ` / task, including tab / 1–4 space CommonMark padding), footnote-definition openers (`[^1]: `), and inline chrome (`[` / `](url)` / `[ref]`, `**` / ticks, CommonMark code-span padding spaces inside `` ` foo ` ``, wrapping `**` around `[hello](url)` / `![alt](url)` / `<b>hello</b>` / `<img>`, autolink `<>`, `$math$` / `[[wiki]]` / `:emoji:`) are not caret homes: Home/click/Left/Right skip them like fence prefixes (`clamp_raw_prefix` plus descendant `inline_ranges` on quote/list containers; `skip_inline_delimiter_chrome` for inline dest/marks). End/DocumentEnd on a last-in-line markdown link stay on the label `]` (`line_end_caret` / `document_end_caret`), not hidden dest `(url)` / `[ref]`. Last-in-line HTML `<a href>label</a>` / `<b>` / comments stay on the inner text (before `</a>` / `</b>` / `<!--`), not dest `href` and not the last inner letter. Home/End in a GFM table stay in the current cell (`line_start_caret` / `line_end_caret`; quoted / compact / a last-in-cell markdown or HTML link too); DocumentEnd still leaves the row. Empty `> ` / `- ` / `[^1]: ` / `: ` lines are still caret homes after the prefix (`empty_prefix_homes`) so typing is `> x` / `- x` / `[^1]: x` / `: x`. InsertText at that home on `>` (and quoted empty lists `>-` / `> -` / `>*`) without the marker space inserts the space (`> x`, not `>x`). Unquoted `-` / `*` do not auto-space (input rules for `---` / italic). Nested quotes skip every `>` onto body text. Wrapped list continuation indent is skipped the same way. A markdown soft wrap (`hello\nworld`) and a hard break (`a  \nb`) paint a space / newline whose click/IME map onto the break bytes (`SoftBreak` / `HardBreak` `source_range`), not the paragraph start. Two-space / backslash hard-break markers skip like `<br>` (Left/Right/Backspace/Delete are one step; InsertText on the marker lands on the next line's first visible char, or after the previous word at the break start). InsertText on inline `<br>` interiors skips after the widget (`a<br>xb`), not `a<xbr>b`. GFM extended autolinks (`www.`, `https://`, bare email) recover the URL literal when comrak reports `0..1` / a list or quote marker. CommonMark character references (`A&amp;B`) paint the decoded glyph and skip entity dest chrome (click/Home on `&`; Left/Right/Backspace/Delete one step; InsertText on dest chrome skips after the glyph (`A&amp;xB`), not `A&xamp;B`; End on last-in-line `A&amp;` after the glyph, not inside `amp;`; End on last-in-line `[^1]` after the widget, not the label start; linked `[![alt](img)](url)` End stays on wrapping `]`, not dest; code spans stay literal). CommonMark backslash escapes (`A\*B`) paint the decoded glyph and skip the escaped char the same way (click/Home on `\`; InsertText on `*` is `A\*xB`, not `A\x*B`; End on last-in-line `A\*` after the glyph, not on `*`; code spans walk `\` and `*` as literals). YAML frontmatter is not a body caret home (`frontmatter_body_start`: Comrak sourcepos is often `0..0`, so the captured fence `raw` length is the body start). Body commands (InsertText, empty-caret Cmd-B/I/E/K, leftover click, Backspace, …) clamp out of the fences; InsertText/wrap/leftover/SetHeading/list/quote/paste/input-rule at EOF on a closing fence with no following newline insert that newline first (`---\nx` / `---\n**x**` / `---\n# Title`, not `---x` / `---**x**` / `---# Title`). Thematic `---`, HTML `<hr>`, fence ticks (close or last-line opener / info-string), setext `===` / `---` underlines, closed ATX trailing `#`, HTML-block `</div>` / `</p>` / single-line `<pre>…</pre>` / `<div>…</div>`, last-block `<svg>…</svg>` / `<img>` / `<br>`, `[TOC]` / `[[toc]]`, and a GFM table's last `|` match (`===\nx`, `# Title #\nx`, `</div>\nx`, `<pre>…</pre>\nx`, `<svg></svg>\nx`, `[TOC]\nx`, `| 1 | 2 |\nx`; open ATX `# Title` still extends the title). InsertText on a thematic widget opens a paragraph above (`x\n\n---`, not `x---` / a setext heading; quoted keep `>`; HTML `<hr>` / `<br>` leftover/EOF keep a blank line). `SetFrontmatter` / `SetFrontmatterField` still edit the panel. Leading newlines, the blank between top-level blocks (a standard `\n\n` separator, plus extras), and a trailing blank after the last block (`hello\n\n`) with no Comrak empty-paragraph node stay valid caret homes (`blank_caret_gaps`) so a click in the gap does not snap onto the next heading or back into the last paragraph, and Enter-at-start of a heading does not snap onto `# Title`. A click in leftover viewport below the last painted line uses the same trailing-blank home (and opens one when the file has none, so the next insert is a new paragraph) instead of a no-op. Click on the last line of the last block still sits in that paragraph. A document that is only newlines still hosts a caret. A single trailing `\n` is the last block's terminator, not a painted line.
- Fidelity layering: untouched blocks byte-exact automatically; touched blocks keep delimiter fidelity via captured attrs (`*` vs `_`, list markers, ATX/setext, fence char/len, break style) and `raw` slices on inline runs; explicit Normalize ignores fidelity.
- Source-mode masking is a **projection of the same comrak AST**, not a second Markdown parser. tree-sitter-md is gone. Masking + `spans.rs` stay as the source-mode renderer; they are not the WYSIWYG primary.

### Proven invariants (enforced by tests — keep them green)

- **Preserve identity**: `serialize(import(x), Preserve) == x` byte-exact for **all 649** CommonMark spec examples + all corpus cases (`crates/markrust-core/tests/rich_roundtrip.rs`).
- **Normalize fixed point**: `n(x) == n(n(x))` in one step.
- **Meaning preservation**: `html(x) == html(n(x))` under the comrak-HTML oracle.
- 26 documented Normalize-only skips (nested same-mark emphasis — inherent to flat inline runs, Lexical shares it; comrak multi-line inline-HTML literal quirks; link-in-image-alt). Preserve identity still holds for every skip.
- Byte-exact save round-trip e2e (`task_table_fence_frontmatter_survive_save_roundtrip`) still passes.
- Source spans share kinds with the rich tree on `showcase.md` (`source_spans_share_comrak_grammar_with_rich_tree`).
- Dirty-tab disjoint external edits merge (`dirty_tab_merges_disjoint_external_edits`).
- Load+parse of a 256 KiB mixed GFM fixture stays under 2.5s (`large_document_load_and_parse_stays_under_budget`); source layout of a 64 KiB fixture under 2.5s (`large_document_layout_stays_under_budget`). `cargo bench -p markrust-core --bench parse` and `cargo bench -p markrust-editor --bench layout` for local criterion numbers.

## P4 shipped

Editing core is in: `rich/command.rs` (`InsertText`, `Backspace`, `Delete`, `SplitBlock`, `InsertLineBreak`, `ToggleMark`, `ToggleLink`, `SetBlockType`, `ToggleBlockquote`, `ToggleList`, `SetTaskChecked`, `IndentList`, `OutdentList`), `UndoStack` `Transaction` with typing coalescing and caret restore, WYSIWYG caret/selection/hit-testing via `block_text.rs`, IME (`EntityInputHandler`, preedit does not touch the model). Default tab mode is WYSIWYG (`default_editor_mode_is_wysiwyg_not_split`). `cmd-shift-m` cycles Wysiwyg → Source → Split.

Proven by tests: insert in one block leaves other blocks' bytes untouched; coalesced typing undo restores string + caret; backspace deletes the visible grapheme not `**` wrappers; backspace at list-item start strips the marker (quoted lists keep `>`); backspace at heading start strips `#` / setext underline (quoted headings keep `>`; heading-in-list strips `#` before the list marker); split paragraph/list; empty ATX heading Enter (levels 1–6) converts to a paragraph; Enter at the start of a non-empty heading inserts a blank paragraph above (heading kept; quoted keep `>`; list-item headings insert a blank list item; caret stays on the blank through snap — it does not jump onto `# Title`; arrow-up from the heading can sit on that blank); a standard `\n\n` between top-level blocks is a clickable empty line (typing inserts a paragraph there, not heading chrome); a trailing blank after the last block (`hello\n\n`) is the same clickable empty line (typing appends a paragraph; a lone terminator `\n` is not painted); leftover viewport below the last painted line places that trailing-blank caret (and opens a trailing blank when the file has none, so typing is a new paragraph; click on the last line still continues that paragraph); a newlines-only document still hosts a caret; non-empty heading Enter mid/end splits like a paragraph; toggle bold (selection wraps; empty caret inserts `****` with the caret inside); wrap link (empty whitespace inserts `[]()` with the caret in the label; a selection or word is wrapped as `[hello]()` with the caret in the URL; typing fills that dest); empty-item Enter outdents/exits (quoted empty lists become `> `); empty blockquote Enter exits; indent/outdent (quoted Tab indents after `>`, not before); task checkbox splice.

- **Remote images and data URLs:** opening a Markdown file never sends a network request. The reader must click **Load images** (or use the command palette) for the current tab; that consent is not persisted. ## Dev workflow — hard-won gotchas

- **Build env**: `export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` — `xcode-select` points at CommandLineTools, which lacks the Metal shader compiler (`xcrun: unable to find utility "metal"`).
- **Always `cargo build --workspace`** before running `target/debug/markrust`: building `-p markrust-app` rebuilds only the lib — the `markrust` bin package stays stale (this burned a debugging hour).
- **gpui font-kit**: `gpui_platform` must keep `features = ["font-kit"]` or macOS gets a silent `NoopTextSystem` and renders no text at all.
- **gpui run invariants**: `TextRun`s passed to `shape_line`/`StyledText::with_runs` must exactly tile the text on char boundaries; tree-sitter *code* highlight spans nest/overlap and must be sanitized first (see `wysiwyg/blocks.rs::code_runs` and `source/element.rs::build_runs_for_line`).
- **Visual verification**: run the app, `screencapture -x out.png` (needs sandbox disabled → permission prompt), read the PNG. Launching the app steals focus — batch checks and kill instances promptly; every panic-abort also spawns a macOS crash dialog for the user.
- **Panic analysis**: panics append structured reports (message, location, full backtrace) to `~/Library/Logs/MarkRust/panics.log` via `markrust_app::crash::install_panic_logger()`. Check that file first when the app dies; it is written before the crash dialog appears.
- `cargo test/build` piped to `grep`/`tail` masks exit codes — check `pipestatus` or run unpiped.
