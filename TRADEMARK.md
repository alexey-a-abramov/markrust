# MarkRust trademark policy

**MarkRust** is a trademark of Alexey Abramov.

## Permitted uses

- Referring to this project in truthful statements ("Built with MarkRust")
- Community forks that clearly state they are unofficial and not affiliated
- Naming that follows the pattern "Based on MarkRust" or "MarkRust-compatible"

## Restricted uses

- Using **MarkRust** in a product name that implies official endorsement
- Registering confusingly similar names for competing Markdown editors
- Using the MarkRust logo (when published) without permission

For questions, open a discussion on the GitHub repository.
