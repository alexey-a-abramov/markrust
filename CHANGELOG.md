## [Unreleased]

### Added

- Native macOS menu bar and compact monochrome toolbar icons. WYSIWYG, Source,
  and Split modes have separate selected segments, tooltips, View menu entries,
  and Cmd-1/2/3 shortcuts; mode changes preserve selection and focus the active
  editor. Narrow windows collapse or float side panels to keep the document usable.
- A native GUI regression runner with real text shaping, layout and input
  assertions, Metal screenshots, explicit pixel-baseline comparison, and a
  GPU-independent macOS CI lane.
- WYSIWYG Typora-style intersect-reveal for definition-list `: ` and footnote definitions `[^1]:` (and footnote refs `[^1]`): hidden when the caret is outside the details/def/ref; painted when the caret or a selection intersects. Click on details/body text still maps into the word. Keyboard skip of those markers is unchanged.
- WYSIWYG Typora-style intersect-reveal for thematic breaks (`---` / `***` / `___` / `* * *`) and HTML-block `<hr>`: the rule paints when the caret is elsewhere; source paints when the caret or a selection intersects. Click on the rule maps to the break; click on a revealed `-` maps onto that source byte. Left/Right/Delete stay one step (not nibbleable dashes or tag bytes).
- WYSIWYG HTML-block wrapper tags (`<div>` / `</div>`) paint when the caret or a selection intersects the block; inner Markdown (`**bold**`, links, code) still paints as rich text. Tags are not nibbleable.
- WYSIWYG keeps GFM link/image reference definitions (`[ref]: url`) as editable blocks (comrak detaches them from the AST). `[` `]` hide unless the caret intersects; dest stays visible. Editing dest updates `[label][ref]` resolution; copy is markdown. Click/Home skip `[` onto the label and `: ` onto dest; Backspace at dest start does not nibble `:`. Nested `[ref]:` in a list/quote/task item keeps `[hello][ref]` / `![alt][ref]` as links (not a bracketed text run).
- WYSIWYG Typora-style intersect-reveal for HTML phrasing tags (`<b>` / `<em>` / `<a href>` / `<mark>` / `<sub>` / comments, …): hidden when the caret is outside the tag span; painted when the caret or a selection intersects (same rule as wrap marks). Click on painted inner text still maps into the word; click on a revealed tag maps onto those source bytes. Keyboard skip of tag dest chrome is unchanged. `<br>` / `<img>` / `<svg>` stay widgets; `script` / `iframe` stay hidden.
- WYSIWYG Typora-style intersect-reveal for list/task markers, quote `>`, fence ticks (and the info string), and table `|` (plus the alignment row): hidden when the caret is outside the item / quote / fence / table; painted when the caret or a selection intersects (same rule as source-mode masking). Click on painted body text still maps into the word. Home/click skip hidden table `|` onto the cell; keyboard prefix skip is otherwise unchanged. Wrap marks, ATX `#`, setext underlines, and link/image chrome already used this rule.
- WYSIWYG Typora-style intersect-reveal for markdown links and images: `[` `]` paint when the caret or a selection intersects the link; dest `(url)` / `[ref]` stays hidden while the caret is only in the label and paints when the caret is in dest or a selection overlaps the node (source-masking intersect). Images paint `![]()` when intersected. Setext underlines reveal with the heading. Click on painted `label` still maps into the word. Keyboard dest-chrome skip is unchanged. Wrap marks and ATX `#` already used this rule.
- WYSIWYG Typora-style intersect-reveal: wrap marks (`*` / `**` / `_` / `__` / `~~` / ticks / `==`) and ATX `#` paint when the caret or a selection intersects the node and stay hidden otherwise. Nested spans are independent. Click on painted `bold` still maps into the word; click on a revealed delimiter maps onto those source bytes. Math / wiki / emoji / autolink `<>` / alerts already used this rule.
- WYSIWYG paints GitHub/Typora emoji shortcodes (`:smile:`, `:heart:`, `:+1:`, `:rocket:`, …) as Unicode (a modest built-in alias table). `:name:` is hidden unless the caret intersects; unmatched `:foo:` stays visible; on-disk bytes stay `:name:`. Source mode substitutes the same glyphs when the caret is outside.
- WYSIWYG `[[wikilink]]` / `[[target|label]]` paint as in-place links (`[[ ]]` hidden unless the caret intersects). `[TOC]` / `[[toc]]` paint a generated heading list from the document outline (marker shown when the caret intersects); Home/click skip the brackets onto the name. Source bytes stay in the file. Source mode masks wiki brackets with the same caret/selection rule as `**`.
- Parse/layout perf gates: 256 KiB mixed GFM load+parse timeout tests, 64 KiB source-layout timeout tests, plus criterion benches (`cargo bench -p markrust-core --bench parse`, `cargo bench -p markrust-editor --bench layout`).
- Contextual table toolbar when the caret is in a table (row/col insert and delete). Right-click still focuses the cell.
- Frontmatter panel edits title, description, tags, and the inner YAML body.
- Input rules: `[` / `]` / `<` type unescaped so task lists, links, and HTML can be typed; `# ` / lists / quotes / fences stay literal inside table cells (they do not rewrite the GFM row or insert newlines / `|`).
- Side-by-side editor mode: `cmd-shift-m` cycles Wysiwyg → Source → Split.
- Dirty-tab 3-way merge when a file changes on disk; carets are mapped across the merge.
- Normalize-on-save dialog shows a line hunk preview.
- Chip/caption/frontmatter overlays accept click/drag and Left/Right (Shift extends the inner selection; Home/End are line-local; YAML Up/Down moves between `\n` lines) to place an inner caret without moving the body caret. Delete in those overlays deletes in the field. Typing, Backspace, and Delete replace or delete a non-empty inner drag-selection. Cmd+A selects the overlay draft (not the document). Undo/Redo while the overlay is focused rewinds those draft edits; Escape still cancels and click-away still commits into document undo. Widget IME origin is that inner `|` / caret rect (`compute_ime_candidate_bounds` / `PlatformImeSpy`), not the overlay’s trailing right edge. The OS IME candidate window is still unverified.
- WYSIWYG local images render as pixels from a background-validated, content-addressed cache copy (bounded bytes, supported raster formats, a pixel budget, and strict SVG validation) with alt/caption still editable. `data:` images use the same cache-only `PathBuf` pipeline rather than reaching GPUI as URIs. Mixed text+image paragraphs lay out as a wrapping horizontal line-box (inline images capped at 1.5em); a standalone image paragraph stays block-sized. Remote `http(s)` images fetch off the UI thread into a URL-keyed cache, then use the same `PathBuf` pipeline; timeouts and failures keep the alt placeholder. Thematic breaks, autolink paint, strikethrough, and hard-break newlines match the rendered document instead of source chrome.
- WYSIWYG paints safe inline and block HTML instead of raw tags (phrasing marks, `<br>`, comments hidden unless the caret intersects, script/iframe/`javascript:` dropped). HTML-block inner Markdown (`**bold**`, links, code) paints as rich text. `==highlight==` / `<mark>` paint a background; `<sub>`/`<sup>` and `~sub~`/`^sup^` use Unicode (GPUI has no per-run baseline). Footnote references paint as superscripts; footnote definitions and definition lists paint as structured blocks whose bodies are nested rich trees (`**bold**`, links, code). `$…$` / `$$…$$` hide the dollars unless the caret intersects and paint the TeX in italic monospace (currency like `$5` and `$` in code stay text). GitHub `> [!NOTE]` / TIP / IMPORTANT / WARNING / CAUTION alerts paint as labeled callouts (left rule + label; `[!NOTE]` hidden unless the caret intersects). Parse still uses the background worker; the folder watcher still `recv`s off the UI thread. Mermaid fences stay code blocks (no small in-process SVG renderer without a large layout crate).

### Changed

- Replacing selected text and using Paste are atomic undo actions: Undo restores
  the replaced text and selection direction without consuming adjacent typing.
- Wrapped text reserves height using its actual parent width. Narrow table
  cells and list items no longer paint over following rows, and selection
  highlights follow individual visual lines instead of forming tall blocks.
- Native input remains registered after trailing whitespace and when no
  painted leaf owns the caret. Typing no longer stops after a space at EOF.
- Source and Split views expose horizontal scrolling for long unwrapped lines;
  keyboard navigation and narrower viewports keep the source caret visible.
- HTML export is now safe by default: raw HTML and dangerous URL schemes are omitted from output. For deliberately trusted Markdown, the CLI provides an explicit `markrust export --unsafe-html …` escape hatch that preserves the prior Comrak behavior.
- WYSIWYG InsertText on CommonMark `&amp;` / `\*` dest chrome and inline `<br>` interiors skips onto the next visible character (`A&amp;xB`, `A\*xB`, `a<br>xb`), not glue `A&xamp;B` / `A\x*B` / `a<xbr>b`. The widget start still extends the previous word (`Ax&amp;B`, `ax<br>b`). Code spans stay literal. P5 stays 🚧.
- WYSIWYG InsertText on a thematic `---` / `***` / `___` / `<hr>` widget opens a new paragraph above (`x\n\n---`, not `x---` / a setext heading). Quoted keep `>`. Close-edge / leftover-below / EOF open after; HTML type-6 `<hr>` / type-7 `<br>` keep a blank line so the next paragraph is not swallowed (`<hr>\n\nx`). Atomic Left/Right/Delete stay one step. Empty wrap `****` still fills as `**x**`. P5 stays 🚧.
- WYSIWYG InsertText on two-space / backslash hard-break chrome skips onto the next line's first visible character (`a  \nxb`); the break start still extends the previous word (`ax  \nb`). Quoted / list match. Wrap still wraps the marker. P5 stays 🚧.
- WYSIWYG InsertText on setext underline / closed ATX trailing hashes / leading table `|` / GitHub `[!NOTE]` skips onto the title, first cell, or alert body (`Titlex\n===`, `# Titlex #`, `| xa |`, `> [!NOTE]\n> xbody`), not glue `Title\n===x` / `# Title #x` / `x| a |` / `x[!NOTE]`. Document EOF on underline / trailing hashes still opens a body line. Open ATX `# Titlex` and cell-end `hellox|` stay. Empty wrap splice on `[!NOTE]` / `[TOC]` unchanged. P5 stays 🚧.
- WYSIWYG InsertText on GFM `<https://…>` / `$math$` / `[[wiki]]` / dest `(` / `"title"` dest chrome skips onto inner (`<xhttps://…>`, `$xx^2$`, `[[xpage]]`, `[hello](xurl)`), not glue `x<https://` / `x$x^2$` / `[hello]x(url)`. Quoted / list / table match. Empty wrap still wraps autolink / image widgets. Wrap-mark `*` and standalone image `!` stay put. P5 stays 🚧.
- WYSIWYG InsertText on HTML-block wrapper tags (`<div>` / `<p>` / inner `<span>`) skips onto inner markdown (`<div>xhello</div>`), not glue `x<div>`. Typing on `</div>` opens a body paragraph after the block (leftover-below / `</div>` EOF newline). Tags are not nibbleable. Quoted keep `>`. Empty wrap on inline `<!--` dest chrome wraps the widget (`**<!-- x -->**`), not splice `**x**<!--`. InsertText inside `<!--` sits in comment inner; End before `<!--` still extends the previous text (`hellox<!--`). P5 stays 🚧.
- WYSIWYG InsertText on revealed list/quote/task/`[ref]:` prefixes skips onto the body (`> xhello`, `- [x] xdone`, `[xref]: url`), not splice `x> hello` / `1. x[x] done` / `x[ref]:`. Colon after `[ref]` still types into dest. Cell-end `|` stays the End insert home. P5 stays 🚧.
- WYSIWYG empty wrap / InsertText on markdown-link `[`, HTML phrasing open tags (`<b>` / `<a href>`), and GFM table alignment dashes skip onto inner text (`[**x**hello](url)`, `<b>**x**hello</b>`, type in a cell not `|x---|`). Trailing paragraph space still inserts `[]()` there. `[TOC]` / alert wrap splice unchanged. P5 stays 🚧.
- WYSIWYG empty-caret wrap on ATX `#`, setext underlines, table `|`, and 0–3 space heading indent: Cmd-B/I/E/K sits in the body (`# **x**Title`, `| **x**a |`), not splice `**x**#` / `**x**|` / `[]()#`. Closed trailing hashes wrap at the title end. Leftover below a heading still opens a paragraph. List/quote/task/`[^1]:` and wrap-mark openers already skipped. P5 stays 🚧.
- WYSIWYG Enter / Shift-Enter inside wrap marks / inline code / HTML phrasing stays one node (`**bo\nld**`, `` `co\nde` ``, `<b>he\nllo</b>`, `<a href>la\nbel</a>`; quoted keep `>`; list-nested does not open a sibling item). Shift-Enter in emphasis is a hard break; code / HTML stay a raw newline. ATX `# **hello**` splits after the heading line so the wrap is not broken. A paragraph `\n\n` split used to orphan the closer as prose. P5 stays 🚧.
- WYSIWYG Enter / Shift-Enter inside a GFM `[hello](url)` / `[hello][ref]` / `![alt](url)` / `<https://…>` / `www.` autolink stays one node. Mid-label Enter is a soft wrap (`[hel\nlo](url)`; quoted keep `>`; list-nested does not open a sibling item). Dest/autolink Enter splits after the node (URLs cannot wrap). Titles wrap. ATX headings split after the heading line so `# [hello](url)` is not broken. A paragraph `\n\n` split used to orphan dest/label as prose. P5 stays 🚧.
- WYSIWYG Enter / Shift-Enter in a GFM `[ref]:` dest stays one definition (`[ref]: https://ex.com/pa` + Enter + `th` is `pa\\\nth`; quoted keep `>`). A paragraph `\n\n` split used to orphan dest as prose. Empty `[ref]: ` Enter strips the opener like empty `[^1]: ` / empty list. `[hello][ref]` resolution stays. P5 stays 🚧.
- WYSIWYG Enter / Shift-Enter inside `$x^2$` / `$$\nE=mc^2\n$$` stays in the TeX (`E\n=mc^2` still display math; quoted keep `>`; list-nested does not open a sibling item). A paragraph `\n\n` split (or `\\\n` hard break) used to break the dollars. Enter after the closer still splits the paragraph. P5 stays 🚧.
- WYSIWYG Enter in the middle of a footnote definition keeps the rest of the note inside `[^1]:` (`the no\nte`; quoted keep `>`). A paragraph `\n\n` split no longer orphans the tail as prose. Enter at the end of a non-empty def still opens a paragraph. Empty `[^1]: ` Enter strips the opener (quoted keep `>`). Nested lists inside the def still continue as lists. P5 stays 🚧.

- WYSIWYG Shift-Enter (hard break) in quotes, lists, tasks, and GitHub alerts keeps container prefixes on the next line (`> hello\` / `> x`, `- hello\` / indented `x`, quoted lists, nested `> >`, `> [!NOTE]`). Paragraphs stay `hello\`. Tables stay `<br>`. Fences stay raw newlines. P5 stays 🚧.
- WYSIWYG keyboard End on last-in-line footnote refs `[^1]` / unmatched `[^missing]` stays after the widget, not on the label start. End / DocumentEnd / Cmd-Delete-to-line-end match (heading / list / quote / table cell / CRLF too). Typing at End is `Hello[^1]x`. Linked `[![alt](img)](url)` End stays on wrapping `]`, not dest (standalone `![alt](url)` stays atomic). P5 stays 🚧.
- WYSIWYG paste-as-markdown: clipboard InsertText that is not a typed keystroke stays GFM (Copy of `[hello](url)` / `**bold**` / `![alt](url)` no longer pastes as `\[hello](url)` / `\*\*bold\*\*` / `\![alt](url)`). - WYSIWYG keyboard End on last-in-line `&amp;` / `&lt;` / `&#123;` / `&#x7B;` stays after the painted glyph, not inside hidden `amp;` dest chrome. End / DocumentEnd / Cmd-Delete-to-line-end match (heading / list / quote / table cell / CRLF / numeric `&#38;` too). Typing at End is `A&amp;x`. Last-in-line `\*` / `\\` match. - WYSIWYG keyboard End on a last-in-line HTML `<a href>label</a>` stays on the label (before `</a>`), not hidden dest `href` and not the last inner letter. End / DocumentEnd / Cmd-Delete-to-line-end match (heading / list / quote / wrap / CRLF / `<b>` / `<em>` / comments / PI / CDATA too). Cmd-Delete-to-line-end / Cmd-Backspace-to-line-start match; typing at End extends that cell. A last-in-cell markdown link still Ends on the label `]`. DocumentEnd still leaves the row. P5 stays 🚧.
- WYSIWYG keyboard End on a last-in-line markdown link stays on the label (`]`), not hidden dest `(url)` / `[ref]` / empty `()`. End / DocumentEnd / Cmd-Delete-to-line-end match (heading / list / quote / CRLF too). Typing at End extends the label; dest inner is the End stop only when the caret is already in dest. Autolink `<>` / wrap marks still End on inner.end. P5 stays 🚧.
- WYSIWYG empty-caret wrap on GFM task checkboxes and strikethrough openers: Cmd-B/I/E/K on `[x]` / `[ ]` sits in the item body (`- [ ] **x**`, not splice `****[x]` / `[]()[x]` or wrap the checkbox as a mark). Empty wrap on `~~strike~~` (and GFM `__strong__`) skips onto inner text like `**bold**` (not splice `****~~`). Leftover below a last-block task still opens `[]()`. Cmd-K in dest `()` is unchanged. - Left / Right / Shift-Left / Right / Home / End in a language chip, image caption, or frontmatter overlay move the inner caret (Shift extends the inner selection) instead of the document body. Delete in those overlays deletes in the field.
- Tab / Shift-Tab on a list item inside a blockquote indents and outdents after the `>` markers (`>   - item`), and outermost Shift-Tab becomes a quoted paragraph (`> item`) instead of putting a space before `>`. Source-mode Tab on a quoted line indents after `>` the same way (`> hello` → `>   hello`); source-mode Shift-Tab strips that indent after `>` (`>   hello` → `> hello`) and does not eat `>` or a space before it.
- Backspace at the start of a list item (quoted or not) removes the list marker (Typora) instead of deleting a body grapheme or eating `>` one character at a time.
- Cmd/Ctrl+B/I/E/K on an empty image caption or frontmatter field inserts wrap marks with the caret inside, so typing becomes `**x**` rather than `****x`.
- Enter on an empty list item inside a blockquote (`> - `, `> 1. `, `> - [ ] `) now exits the list and keeps the quote (`> `). Nested quotes keep their depth (`> > - ` → `> > `). Enter on a non-empty quoted list item continues the quoted list.
- Cmd/Ctrl+B/I/E/K while an image caption or frontmatter field is focused wrap that field instead of committing and toggling the document body. The fenced-code language chip ignores wrap (does not bold the body).
- Enter in a WYSIWYG table cell now inserts `<br>` (a line break in the cell) instead of splitting the GFM row into a new paragraph. `InsertLineBreak` uses the same path so a bound Shift-Enter cannot splice `\\\n` into the row.
- Empty blockquote Enter now leaves the quote (Typora: same as an empty list item). Nested empty quotes outdent one `>` level.
- Tab in a fenced-code language chip, image caption, or frontmatter overlay commits that field and no longer indents the document body.
- Shift-Enter inserts a Markdown hard line break (`InsertLineBreak`; `<br>` in table cells). Bound like Enter (same on Cmd and Ctrl platforms).
- Tab / Shift-Tab in a WYSIWYG table cell now moves between cells (and Tab on the last cell inserts a row) instead of inserting indent spaces. The same path works when the caret is inside inline code in a cell.
- Opening a Markdown file no longer freezes the window: the folder watcher no longer blocks GPUI's UI thread, and Markdown parse stays on the background worker.
- Empty list-item Enter outdents or exits the list instead of inserting a blank paragraph in place.
- Source-mode line height for a heading vs body line is derived from syntax spans, not mask visibility.
