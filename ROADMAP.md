# MarkRust Roadmap

## v0.1.0 — Public alpha

- [x] Phase 0: Bootstrap (workspace, CI, core buffer)
- [x] Phase 1: Core engine (tree-sitter spans, background parse)
- [x] Phase 2 (headless): Delimiter masking algorithm + tests
- [ ] Phase 2 (GUI): GPUI editor surface, caret, selection, themes
- [ ] Phase 3: Workspace shell (folder, file tree, outline, palette)
- [ ] Phase 4: GFM completeness (tables, task lists, export)
- [ ] Phase 5: Distribution (release binaries, Homebrew, crates.io)

## Explicitly deferred

- Split/source editing mode
- Git UI integration
- MCP / AI agent server
- Cloud sync and accounts
- Plugin marketplace
- Math/LaTeX rendering
- Windows port (target v0.2)

See the full product plan in the repository docs for rationale and milestones.
